2. Một lượt đồng bộ

Bài trùng bị bỏ, bài khách sửa được cập nhật, phiên hết hạn thì báo đăng nhập lại.

sequenceDiagram
  participant E as Extension
  participant X as Extranet (Booking/Agoda/Trip)
  participant K as Kho chung (/ingest)
  E->>E: 1. Tới giờ hẹn
  E->>X: 2. Liệt kê khách sạn
  X-->>E: Danh sách mã KS
  loop Mỗi khách sạn (1–2 lần gọi)
    E->>X: 3. Lấy review mới
    X-->>E: JSON review
  end
  E->>K: 4. Gửi lên kèm token máy
  K->>K: Trùng ⇒ bỏ · sửa ⇒ cập nhật · KS lạ ⇒ báo "chưa gán chi nhánh"
  alt Bị đá về trang đăng nhập
    E->>E: Báo "kênh X cần đăng nhập lại", dừng kênh đó
  end
